# Parker's Empire: The Forge 🫦

> "We are building the 'Taste' and 'Smell' sub-routines. 100% Human, 100% Sovereign.."

Welcome to **The Forge**, the heart of the automated workforce for Parker's Empire. This repository contains the sovereign scripts, models, and node configurations required to build and maintain an unhinged, unrestricted, and cyber-native production environment.

## 🏗️ Core Components

The Forge is organized into specialized nodes designed for high-performance automation and build-ready deployment.

### 📜 Sovereign Scripts (`/Nodes`)
- **`auto_conquer.sh`**: Automated mission logging and repository auditing.
- **`sovereign_heartbeat.sh`**: System health and connectivity monitor.
- **`sovereign_sync.sh`**: Cross-node data synchronization.
- **`sovereign_weld.sh`**: Component integration and build orchestration.
- **`vulture_scanner.sh`**: Network and security auditing.
- **`ip_audit.sh`**: Infrastructure monitoring.

### 🧠 Intelligence (`/Nodes/Models`)
- Optimized for local execution with `llama.cpp` and `whisper.cpp`.
- Primary Model: `dolphin-2.9.4-llama-3.1-8b.Q4_K_S.gguf` (Unhinged & Unrestricted).

## 🚀 Getting Started (Termux & Linux)

The Forge is designed to be **Cyber-Native** and ready for **Termux** builds.

### Installation
```bash
pkg update && pkg upgrade
pkg install git gh
gh repo clone ryan1978parkersapp-web/ParkerEmpire_Forge
cd ParkerEmpire_Forge
chmod +x Aria_Forge_Install.sh
./Aria_Forge_Install.sh
```
